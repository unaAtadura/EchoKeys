# EchoKeys

一款专为计算机教学演示设计的键鼠操作可视化工具，让观众能够清晰地看到演示者的每一次按键和鼠标操作。

## 功能特性

### ⌨️ 按键可视化
- **实时显示**：按下的按键即时显示在屏幕上
- **组合键识别**：自动识别并显示 `ctrl + c`、`ctrl + shift + s` 等组合键
- **智能合并**：快速连续输入的字母数字会自动合并显示
- **历史记录**：最多保留最近 6 条操作记录
- **自动消失**：每条记录 5 秒后自动消失，保持屏幕整洁

### 🖱️ 鼠标高亮
- **左键点击**：黄色圆形跟随光标移动
- **右键点击**：粉色圆形跟随光标移动
- **左右键同时按下**：蓝色圆形显示
- **即时反馈**：释放鼠标键后立即消失

### 🎯 位置智能
- 根据圆形窗口位置，自动选择上方或下方空间较大的一侧显示操作记录
- 靠近屏幕左边缘时左对齐，靠近右边缘时右对齐
- 支持拖拽调整圆形窗口位置

### 🔵 圆形悬浮窗
- 可拖拽的蓝色圆形窗口，始终置顶
- 移动范围限制在屏幕内
- 点击圆形窗口内部不产生操作记录

### 📋 系统托盘
- 支持最小化到系统托盘
- 右键菜单：显示/隐藏窗口、查看日志、退出程序

### 📝 日志窗口
- 可随时打开查看详细操作记录
- 区分显示键盘按下/释放、鼠标点击/释放/滚轮等事件

## 安装

### 环境要求
- Python 3.8+
- Windows 系统

依赖包：
- **PyQt5** - GUI 框架
- **pynput** - 键鼠监听库

## 使用方法

### 运行程序

**方法一：使用 boot.py 启动器（推荐）**

启动器会自动管理虚拟环境、安装依赖，并在后台静默启动程序（无控制台窗口）。

```bash
python boot.py
```

**方法二：使用全局 Python 解释器**

```bash
pip install -r requirements.txt
python EchoKeys.py
```

### 教学演示使用技巧

1. **准备演示**：启动程序后，将蓝色圆形窗口拖拽到不影响演示内容的位置（如屏幕角落）
2. **开始演示**：正常进行操作，按键和鼠标动作会自动显示
3. **查看日志**：如需回顾操作细节，可在托盘菜单中打开日志窗口
4. **退出程序**：在系统托盘右键菜单选择"退出"

### 操作说明

| 操作 | 显示效果 |
|------|---------|
| 按下字母/数字键 | 显示按键内容，快速输入自动合并 |
| 按下组合键（如 ctrl+c） | 显示 `ctrl + c` |
| 按下鼠标左键 | 黄色圆形跟随光标 |
| 按下鼠标右键 | 粉色圆形跟随光标 |
| 同时按下左右键 | 蓝色圆形显示 |
| 滚动鼠标滚轮 | 显示滚轮方向 |

## 技术实现

- **GUI 框架**: PyQt5
- **键鼠监听**: pynput
- **窗口特性**: 无边框、半透明、置顶、鼠标穿透（操作记录和高亮窗口）

## 应用场景

- 软件操作教学视频录制
- 远程技术支持演示
- 编程教学直播
- 快捷键操作演示
- 任何需要展示键鼠操作的场合
