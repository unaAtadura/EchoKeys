# EchoKeys

一个基于 PyQt5 开发的按键显示与鼠标高亮工具，可以在屏幕上实时显示按键和鼠标操作。

## 功能特性

### 🎯 按键显示
- 自动检测键盘和鼠标操作
- 组合键显示（如 `ctrl + c`）
- 快速连续输入的字母数字会合并显示
- 按键历史最多保留 6 条
- 每条记录 5 秒后自动消失

### 🖱️ 鼠标高亮
- 左键按下：黄色圆形跟随光标
- 右键按下：粉色圆形跟随光标
- 左右键同时按下：蓝色圆形跟随光标
- 释放鼠标键后立即消失

### 🔵 圆形窗口
- 可拖拽的圆形半透明窗口
- 始终置顶显示
- 移动范围限制在屏幕内

### 📋 系统托盘
- 最小化到系统托盘
- 右键菜单：显示/隐藏窗口、查看日志、退出程序

### 📝 日志窗口
- 可打开日志窗口查看详细操作记录
- 显示键盘按下/释放、鼠标点击/释放/滚轮等事件

## 安装

### 环境要求
- Python 3.8+
- Windows 系统

### 安装依赖

```bash
pip install -r requirements.txt
```

依赖包：
- **PyQt5** - GUI 框架
- **pynput** - 键鼠监听库

## 使用方法

### 运行程序

```bash
python EchoKeys.py
```

### 操作说明

1. **拖拽圆形窗口**：按住左键拖拽蓝色圆形窗口
2. **查看按键**：按下键盘或鼠标，会在圆形窗口附近显示操作记录
3. **打开日志**：右键点击系统托盘图标，选择"日志"
4. **退出程序**：右键点击系统托盘图标，选择"退出"

## 技术实现

- **GUI 框架**: PyQt5
- **键鼠监听**: pynput
- **窗口样式**: 无边框、半透明、置顶、鼠标穿透（高亮和对话窗口）
